# Tiny Worlds (Thimble Town): 60 Video Ideas

Companion to `Channel-Bible.md`. Cast and style blocks come from Bible §4. Pipeline: SOUL keyframe per section, then **Seedance 2.5 i2v** (default, 720p) or **[CS] = Cinema Studio 4.0** (establishing shots only, always at a hard cut).

**Stitch rules used below:**
- Each section is its own clip. A section over 30s = ceil(sec/30) gens split evenly, each ≥4s, chained seamlessly (the last frame of N is the image_url of N+1). Each segment's prompt says "motion continues" with the same camera move.
- The last segment of each section takes `end_image_url` (the locked end pose).
- Shorts use `end_image_url` = frame-1 keyframe for loops.
- Cost = total seconds × $0.2057 list (video only).

Section format: `n. name — seconds (start time)`. Series tags: Shop Diaries · Build a Tiny · Tiny Seasons · Tiny Travels · Night Lights.
